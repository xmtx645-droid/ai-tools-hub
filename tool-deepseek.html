📖 工具简介

DeepSeek是由中国团队深度求索开发的大型语言模型，以其卓越的性能和极致的性价比在AI领域引起广泛关注。DeepSeek-V3和DeepSeek-R1等模型在多项基准测试中表现优异，甚至在某些任务上可与GPT-4媲美。

特别值得一提的是DeepSeek的API价格——仅为OpenAI的1/100左右，这使得它成为开发者和企业构建AI应用的首选。同时，DeepSeek还提供开源模型，允许本地部署和商用。

性价比无敌：DeepSeek API价格为 0.14元/百万tokens（输入）和 0.28元/百万tokens（输出），是GPT-4价格的1%左右。对于需要大量API调用的应用，能节省90%以上的成本。

💻 开发者示例

Python调用示例：

from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://api.deepseek.com"
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "解释什么是递归"}
    ]
)

print(response.choices[0].message.content)
